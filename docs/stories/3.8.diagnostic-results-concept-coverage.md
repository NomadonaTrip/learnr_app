## Dev Notes

### Architecture Context

This story implements the **Diagnostic Results Screen** - the culmination of the diagnostic assessment flow. After completing 12-20 diagnostic questions (Story 3.6) and having beliefs updated (Story 3.7), users see a comprehensive summary of their initial knowledge profile.

> **DEPENDENCY: Story 3.7 (Diagnostic Belief State Updates)**
> This story requires belief states to have been updated during the diagnostic. The results calculations depend on belief_states having accurate alpha/beta values.

> **DEPENDENCY: Story 3.6 (Diagnostic Assessment UI)**
> Users reach the results screen after completing the diagnostic assessment UI.

> **DEPENDENCY: Story 3.4 (Belief State Initialization)**
> All concepts must have belief states initialized for coverage calculations to work.

**Key Design Decisions:**

- **NOT "You scored 72%"** - This would be false precision. Instead: "We've started mapping your knowledge. Here's what we know so far."
- **Coverage-focused messaging** - Emphasizes what percentage of concepts were touched, not a single score
- **Confidence levels** - "initial", "developing", "established" based on response_count distribution
- **Actionable recommendations** - Direct users to their weakest KA for focused study

### BKT Classification Thresholds

From the architecture, these thresholds determine concept classification:

```python
# Classification thresholds (from course config, defaults shown)
MASTERY_THRESHOLD = 0.8   # mean >= 0.8 = mastered
GAP_THRESHOLD = 0.5       # mean < 0.5 = gap
CONFIDENCE_THRESHOLD = 0.7 # confidence >= 0.7 = classified

# Computed properties
mean = alpha / (alpha + beta)
confidence = (alpha + beta) / (alpha + beta + 10)

# Status classification
if confidence < CONFIDENCE_THRESHOLD:
    status = "uncertain"
elif mean >= MASTERY_THRESHOLD:
    status = "mastered"
elif mean < GAP_THRESHOLD:
    status = "gap"
else:
    status = "borderline"
```

#### GET /api/v1/diagnostic/results

Get diagnostic results summary after completing the assessment.

**Request Headers:**

- `Authorization: Bearer <jwt_token>` (required)

**Error Responses:**

- `401 UNAUTHORIZED`: Missing or invalid JWT token
- `404 NOT_FOUND`: No completed diagnostic found for user

**Notes:**

- `confidence_level` values: "initial" (< 30% coverage), "developing" (30-70%), "established" (> 70%)
- `estimated_mastered` counts concepts with mean >= 0.8 AND confidence >= 0.7
- `top_gaps` returns up to 10 concepts sorted by lowest mastery_probability

### Service Architecture

#### DiagnosticResultsService

```python
# apps/api/src/services/diagnostic_results_service.py
from typing import List
from uuid import UUID
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, func, and_

from src.models.belief_state import BeliefState
from src.models.concept import Concept
from src.schemas.diagnostic_results import (
    DiagnosticResultsResponse,
    KnowledgeAreaResult,
    ConceptGap,
    Recommendations
)

class DiagnosticResultsService:
    """
    Computes diagnostic results from belief states after diagnostic completion.
    """

    MASTERY_THRESHOLD = 0.8
    GAP_THRESHOLD = 0.5
    CONFIDENCE_THRESHOLD = 0.7

    def __init__(self, db: AsyncSession, course_id: UUID):
        self.db = db
        self.course_id = course_id

    async def compute_diagnostic_results(
        self,
        user_id: UUID
    ) -> DiagnosticResultsResponse:
        """
        Compute comprehensive diagnostic results for a user.
        """
        # Get all belief states for user's course
        beliefs = await self._get_all_beliefs(user_id)

        # Compute totals
        total_concepts = len(beliefs)
        concepts_touched = sum(1 for b in beliefs if b.response_count > 0)
        coverage_percentage = concepts_touched / total_concepts if total_concepts > 0 else 0

        # Classify beliefs
        estimated_mastered = 0
        estimated_gaps = 0
        uncertain = 0
        gap_candidates = []

        for belief in beliefs:
            mean = belief.alpha / (belief.alpha + belief.beta)
            confidence = (belief.alpha + belief.beta) / (belief.alpha + belief.beta + 10)

            if confidence < self.CONFIDENCE_THRESHOLD:
                uncertain += 1
            elif mean >= self.MASTERY_THRESHOLD:
                estimated_mastered += 1
            elif mean < self.GAP_THRESHOLD:
                estimated_gaps += 1
                gap_candidates.append((belief, mean))
            # else: borderline (counted in uncertain for this view)

        # Compute confidence level
        confidence_level = self._compute_confidence_level(coverage_percentage)

        # Get per-KA breakdown
        by_knowledge_area = await self._compute_ka_breakdown(user_id)

        # Get top gaps
        top_gaps = self._compute_top_gaps(gap_candidates, limit=10)

        # Generate recommendations
        recommendations = self._generate_recommendations(
            coverage_percentage, by_knowledge_area, uncertain
        )

        return DiagnosticResultsResponse(
            total_concepts=total_concepts,
            concepts_touched=concepts_touched,
            coverage_percentage=round(coverage_percentage, 3),
            estimated_mastered=estimated_mastered,
            estimated_gaps=estimated_gaps,
            uncertain=uncertain,
            confidence_level=confidence_level,
            by_knowledge_area=by_knowledge_area,
            top_gaps=top_gaps,
            recommendations=recommendations
        )

    def _compute_confidence_level(self, coverage: float) -> str:
        """Determine confidence level based on coverage."""
        if coverage < 0.3:
            return "initial"
        elif coverage < 0.7:
            return "developing"
        else:
            return "established"

    def _compute_top_gaps(
        self,
        gap_candidates: List,
        limit: int = 10
    ) -> List[ConceptGap]:
        """Get top gaps sorted by lowest mastery."""
        sorted_gaps = sorted(gap_candidates, key=lambda x: x[1])  # Sort by mean
        return [
            ConceptGap(
                concept_id=belief.concept_id,
                name=belief.concept.name,
                mastery_probability=round(mean, 2),
                knowledge_area=belief.concept.knowledge_area_id
            )
            for belief, mean in sorted_gaps[:limit]
        ]

    def _generate_recommendations(
        self,
        coverage: float,
        ka_breakdown: List[KnowledgeAreaResult],
        uncertain_count: int
    ) -> Recommendations:
        """Generate actionable recommendations."""
        # Find KA with lowest mastery and highest gap ratio
        weakest_ka = min(ka_breakdown, key=lambda ka: ka.estimated_mastery)

        # Estimate questions needed (avg 3 concepts per question)
        estimated_questions = int(uncertain_count / 3)

        # Generate contextual message
        if coverage < 0.3:
            message = f"Good start! Your diagnostic covered {int(coverage * 100)}% of concepts. Continue with adaptive quizzes to build a complete knowledge profile."
        elif coverage < 0.6:
            message = f"Great progress! You've touched {int(coverage * 100)}% of CBAP concepts. Focus on {weakest_ka.ka} to strengthen your weakest area."
        else:
            message = f"Excellent coverage! With {int(coverage * 100)}% of concepts assessed, you have a solid baseline. Keep refining through adaptive study."

        return Recommendations(
            primary_focus=weakest_ka.ka,
            estimated_questions_to_coverage=estimated_questions,
            message=message
```
