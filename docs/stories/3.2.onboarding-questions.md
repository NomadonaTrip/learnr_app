# Story 3.2: Onboarding Questions (3 Questions)

## Status

**Ready for Review**

---

## Story

**As a** prospective user,
**I want** to answer 3 quick onboarding questions about my learning goals,
**so that** the system can personalize my learning path.

---

## Acceptance Criteria

1. User navigates to `/onboarding` (from landing page "Start exam prep" CTA)
2. Present 3 questions sequentially (one at a time)
3. Questions:
   - Q1: "I want to learn..." (course selection buttons - currently only "Business Analysis")
   - Q2: "What's your 'why' for learning [course name]?" (5 options: Personal interest, Certification, Professional development, Career change, Other)
   - Q3: "How familiar are you with [course name]?" (4 options: New, Basics, Intermediate, Expert)
4. Progress indicator: "Question X of 3"
5. Q2 and Q3 dynamically display the selected course name from Q1
6. All questions are required (no skip option)
7. Responses stored in sessionStorage
8. Back button allows changing previous answers
9. After Q3 → navigate to account creation (`/register`)
10. Mobile responsive (375px minimum), accessible (WCAG AA)
11. Analytics: Track question views, completions, and drop-offs
12. Q3 familiarity level maps to initial belief state priors for BKT

```typescript
const familiarityLevels = [
  { id: 'new', label: "I'm new to {course}", prior: 0.1 },

  { id: 'intermediate', label: 'I have intermediate experience', prior: 0.5 },

}: QuestionProps & { courseName: string }) {

      </legend>

          >
            {option.label.replace('{course}', courseName)}
          </button>
        ))}
      </div>
    </fieldset>
  );
}

// Utility to get belief prior from familiarity
export function getFamiliarityPrior(familiarity: string): number {
  const mapping: Record<string, number> = {
    'new': 0.1,
    'basics': 0.3,
    'intermediate': 0.5,
    'expert': 0.7,
  };
  return mapping[familiarity] ?? 0.3; // Default to basics
}
```

### SessionStorage Hook

```typescript
// hooks/useOnboardingStorage.ts
const STORAGE_KEY = 'learnr_onboarding';

export interface OnboardingAnswers {
  course?: string;
  motivation?: string;
  familiarity?: string;
  initialBeliefPrior?: number;
}

export function useOnboardingStorage() {
  const [answers, setAnswersState] = useState<OnboardingAnswers>(() => {
    try {
      const stored = sessionStorage.getItem(STORAGE_KEY);
      return stored ? JSON.parse(stored) : {};
    } catch {
      return {};
    }
  });

  const setAnswer = (key: keyof OnboardingAnswers, value: string | number) => {
    const updated = { ...answers, [key]: value };
    setAnswersState(updated);
    try {
      sessionStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
    } catch (error) {
      console.error('Failed to save onboarding progress', error);
    }
  };

  const clearAnswers = () => {
    setAnswersState({});
    sessionStorage.removeItem(STORAGE_KEY);
  };

  return { answers, setAnswer, clearAnswers };
}
```

### Familiarity → BKT Prior Mapping

The familiarity level from Q3 determines the initial belief state (P(L0)) for Bayesian Knowledge Tracing:

| Familiarity | Prior (P(L0)) | Meaning |
|-------------|---------------|---------|
| New | 0.1 | Low initial mastery assumed |
| Basics | 0.3 | Some foundational knowledge |
| Intermediate | 0.5 | Moderate mastery expected |
| Expert | 0.7 | High mastery, reviewing |

This prior is stored in sessionStorage and will be passed to the backend during account creation (Story 3.3) to initialize the BKT model.
