# Story 2.10: Concept API Endpoints

## Status

Ready for Done

## Story

**As a** backend developer,
**I want** API endpoints for concept data within a specific course,
**so that** internal tools and the adaptive engine can access concept metadata for the user's enrolled course.

> **Note:** These APIs are for system-internal use (adaptive engine, admin tools, debugging). Users see KA-level aggregation only. Concept-level drill-down is a post-MVP optional feature.

## Acceptance Criteria

1. GET `/v1/courses/{course_slug}/concepts` - List all concepts for a course **← CHANGED: course-scoped**
   - Query params: `knowledge_area_id` (filter) **← RENAMED from ka**, `search` (name search), `limit`, `offset`
   - Returns: id, course_id **← NEW**, name, description, corpus_section_ref **← RENAMED**, knowledge_area_id **← RENAMED**, prerequisite_depth
2. GET `/v1/courses/{course_slug}/concepts/{id}` - Get single concept **← CHANGED: course-scoped**
   - Returns: Full concept details with course_id
3. GET `/v1/courses/{course_slug}/concepts/{id}/prerequisites` - Get prerequisite chain **← CHANGED**
   - Returns: Array of prerequisite concepts (ordered by depth) **within the same course**
4. GET `/v1/courses/{course_slug}/concepts/{id}/questions` - Get questions for concept **← CHANGED**
   - Returns: Question count, sample questions **from the same course**
5. GET `/v1/courses/{course_slug}/concepts/stats` - Corpus statistics **← CHANGED**
   - Returns: Total concepts, by KA, by depth, coverage metrics **for the course**
6. All endpoints require authentication
7. Performance: <100ms per endpoint
8. Caching: Concept list cached for 1 hour (concepts rarely change) **keyed by course**
9. **Multi-course:** All endpoints are scoped to the course in the URL path **← NEW**

### Recursive CTE for Prerequisite Chain

```python
from sqlalchemy import text

async def get_prerequisite_chain(
    db: AsyncSession,
    course_id: UUID,        # NEW - required
    concept_id: UUID
) -> List[Concept]:
    """Get all prerequisites using recursive CTE for a specific course."""

    query = text("""
        WITH RECURSIVE prereq_chain AS (
            -- Base case: direct prerequisites
            SELECT
                c.id, c.course_id, c.name, c.description, c.corpus_section_ref,
                c.knowledge_area_id, c.prerequisite_depth,
                1 as chain_depth
            FROM concepts c
            INNER JOIN concept_prerequisites cp ON c.id = cp.prerequisite_concept_id
            WHERE cp.concept_id = :concept_id
              AND c.course_id = :course_id  -- NEW: filter by course

            UNION ALL

            -- Recursive case: prerequisites of prerequisites
            SELECT
                c.id, c.course_id, c.name, c.description, c.corpus_section_ref,
                c.knowledge_area_id, c.prerequisite_depth,
                pc.chain_depth + 1
            FROM concepts c
            INNER JOIN concept_prerequisites cp ON c.id = cp.prerequisite_concept_id
            INNER JOIN prereq_chain pc ON cp.concept_id = pc.id
            WHERE pc.chain_depth < 10  -- Prevent infinite loops
              AND c.course_id = :course_id  -- NEW: stay within course
        )
        SELECT DISTINCT ON (id) *
        FROM prereq_chain
        ORDER BY id, chain_depth
    """)

    result = await db.execute(query, {"concept_id": str(concept_id), "course_id": str(course_id)})
    return result.all()
```

### Stats Aggregation Query

```python
async def get_corpus_stats(db: AsyncSession, course_id: UUID) -> ConceptStats:
    """Get statistics for a specific course."""

    # Total concepts for course
    total = await db.scalar(
        select(func.count(Concept.id))
        .where(Concept.course_id == course_id)  # NEW: filter by course
    )

    # By knowledge area (keyed by knowledge_area_id)
    ka_query = (
        select(Concept.knowledge_area_id, func.count(Concept.id))  # RENAMED
        .where(Concept.course_id == course_id)  # NEW: filter by course
        .group_by(Concept.knowledge_area_id)
    )
    ka_result = await db.execute(ka_query)
    by_ka = {row[0]: row[1] for row in ka_result.all()}

    # By prerequisite depth
    depth_query = (
        select(Concept.prerequisite_depth, func.count(Concept.id))
        .where(Concept.course_id == course_id)  # NEW: filter by course
        .group_by(Concept.prerequisite_depth)
    )
    depth_result = await db.execute(depth_query)
    by_depth = {row[0]: row[1] for row in depth_result.all()}

    # Average prerequisites for course
    avg_prereq_query = (
        select(func.avg(
            select(func.count(ConceptPrerequisite.prerequisite_concept_id))
            .where(ConceptPrerequisite.concept_id == Concept.id)
            .correlate(Concept)
            .scalar_subquery()
        ))
        .where(Concept.course_id == course_id)  # NEW: filter by course
    )
    avg_prereq = await db.scalar(avg_prereq_query) or 0

    # Concepts with/without questions for course
    concepts_with_q = await db.scalar(
        select(func.count(func.distinct(QuestionConcept.concept_id)))
        .join(Concept, QuestionConcept.concept_id == Concept.id)
        .where(Concept.course_id == course_id)  # NEW: filter by course
    )
    concepts_without_q = total - concepts_with_q

    return ConceptStats(
        course_id=course_id,  # NEW
        total_concepts=total,
        by_knowledge_area=by_ka,
        by_depth=by_depth,
        average_prerequisites_per_concept=float(avg_prereq),
        concepts_with_questions=concepts_with_q,
        concepts_without_questions=concepts_without_q
    )
```

### Caching Pattern

```python
from redis import asyncio as aioredis
import json

CACHE_TTL = 3600  # 1 hour

async def get_cached_or_fetch(
    redis: aioredis.Redis,
    cache_key: str,
    fetch_func,
    ttl: int = CACHE_TTL
):
    """Get from cache or fetch and cache."""
    cached = await redis.get(cache_key)
    if cached:
        return json.loads(cached)

    result = await fetch_func()
    await redis.setex(cache_key, ttl, json.dumps(result))
    return result
```
