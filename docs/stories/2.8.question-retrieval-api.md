## Story

**As a** backend developer,
**I want** an API to retrieve questions filtered by concept within a specific course,
**so that** the BKT engine can select questions for specific concepts in the user's enrolled course.

1. GET `/v1/courses/{course_slug}/questions` endpoint accepts: **← CHANGED: course-scoped endpoint**
   - `concept_ids` (array) - filter by concepts
   - `knowledge_area_id` (optional) - knowledge area filter **← RENAMED from ka**
   - `difficulty_min`, `difficulty_max` (optional) - IRT difficulty range
   - `exclude_ids` (array) - questions to exclude (recently asked)
   - `limit` (default 10)

4. Response excludes `correct_answer` and `explanation` (revealed after answer)
5. Pagination metadata included
6. Requires authentication
7. Performance: <100ms for filtered queries
8. Unit tests: Filter by concept, by KA, by difficulty range
9. Integration test: Returns questions for specific concept within course
10. **Multi-course:** Questions are scoped to the course in the URL path **← NEW**

### Database Query Pattern

```python
async def get_questions_filtered(
    db: AsyncSession,
    course_id: UUID,        # NEW - required
    params: QuestionListParams
) -> Tuple[List[Question], int]:
    """Get filtered questions with concept IDs for a specific course."""

    # Base query with concept aggregation
    query = (
        select(
            Question,
            func.array_agg(QuestionConcept.concept_id).label('concept_ids')
        )
        .outerjoin(QuestionConcept, Question.id == QuestionConcept.question_id)
        .where(Question.is_active == True)
        .where(Question.course_id == course_id)  # NEW - always filter by course
        .group_by(Question.id)
    )

    # Apply filters
    if params.concept_ids:
        # Filter by ANY concept match
        concept_subquery = (
            select(QuestionConcept.question_id)
            .where(QuestionConcept.concept_id.in_(params.concept_ids))
            .distinct()
        )
        query = query.where(Question.id.in_(concept_subquery))

    if params.knowledge_area_id:  # RENAMED from ka
        query = query.where(Question.knowledge_area_id == params.knowledge_area_id)

    if params.difficulty_min is not None:
        query = query.where(Question.difficulty >= params.difficulty_min)

    if params.difficulty_max is not None:
        query = query.where(Question.difficulty <= params.difficulty_max)

    if params.exclude_ids:
        query = query.where(Question.id.notin_(params.exclude_ids))

    # Count total before pagination
    count_query = select(func.count()).select_from(query.subquery())
    total = await db.scalar(count_query)

    # Apply pagination
    query = query.offset(params.offset).limit(params.limit)

    result = await db.execute(query)
    questions = result.all()

    return questions, total
```
