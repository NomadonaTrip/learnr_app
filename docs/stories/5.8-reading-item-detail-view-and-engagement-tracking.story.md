# Story 5.8: Reading Item Detail View and Engagement Tracking

## Status

**Ready for Done**

## Story

**As a** user,
**I want to** read individual BABOK chunks in detail and mark them as complete,
**so that** I can learn the material and track my reading progress.

## Acceptance Criteria

1. Clicking "Read Now" on queue item → navigate to detail view OR expand in-place (modal or dedicated page)
2. GET `/api/v1/reading/queue/{queue_id}` retrieves full chunk content
3. Response includes:
   - Full `text_content` (200-500 tokens, formatted markdown or plain text)
   - BABOK section reference, title, KA name
   - Context: Question that prompted recommendation
   - Previous reading history: `times_opened`, `total_reading_time_seconds`
4. Detail view displays:
   - Full reading content (readable formatting, proper line spacing, paragraph breaks)
   - BABOK section reference at top (e.g., "BABOK v3 - Section 3.2.1: Stakeholder Analysis")
   - Context card: "This was recommended because you answered [Question preview] incorrectly"
   - Actions: "Mark as Complete", "Dismiss", "Back to Library"
5. Track engagement automatically:
   - On view load → increment `times_opened`, set `first_opened_at` if first time
   - On view close/navigate away → calculate `time_spent_seconds` (time between load and close)
   - PUT `/api/v1/reading/queue/{queue_id}/engagement` with `time_spent_seconds`
   - Update `total_reading_time_seconds += time_spent_seconds`
6. "Mark as Complete" action:
   - PUT `/api/v1/reading/queue/{queue_id}/status` with `status = 'completed'`
   - Set `completed_at` timestamp
   - Decrement unread badge count
   - Show success message: "Great! Added to your completed reading"
7. "Dismiss" action:
   - PUT `/api/v1/reading/queue/{queue_id}/status` with `status = 'dismissed'`
   - Set `dismissed_at` timestamp
   - Remove from unread count
   - Show confirmation: "Dismissed. You can find this in Dismissed tab if needed."
8. **Bulk dismiss action:** POST `/api/v1/reading/queue/batch-dismiss` endpoint
   - Request body: `{"queue_ids": ["uuid1", "uuid2", "uuid3"]}`
   - Response: `{"dismissed_count": 3, "remaining_unread_count": 4}`
   - Use case: "Dismiss All Low Priority" button on library page
   - All specified queue_ids set to `status = 'dismissed'` with single API call
9. Unit tests: Engagement tracking works, status updates correctly, batch dismiss works
10. Integration test: User can read content, mark complete, batch dismiss, and see badge count update

### API Specifications

**GET `/api/v1/reading/queue/{queue_id}`**

Returns full reading item detail with content.

**Response Schema:**

```json
{
  "queue_id": "uuid",
  "chunk_id": "uuid",
  "title": "Stakeholder Analysis Techniques",
  "text_content": "Full markdown content of the reading chunk...\n\nMultiple paragraphs with proper formatting...",
  "babok_section": "3.2.1",
  "ka_name": "Elicitation and Collaboration",
  "priority": "High",
  "status": "unread",
  "word_count": 450,
  "estimated_read_minutes": 2,
  "times_opened": 3,
  "total_reading_time_seconds": 180,
  "first_opened_at": "2025-12-24T10:00:00Z",
  "question_context": {
    "question_id": "uuid",
    "question_preview": "Which technique is BEST for identifying stakeholder...",
    "was_incorrect": true
  },
  "added_at": "2025-12-24T09:30:00Z"
}
```

**PUT `/api/v1/reading/queue/{queue_id}/engagement`**

Updates reading engagement metrics.

**Request:**

```json
{
  "time_spent_seconds": 120
}
```

**Response:**

```json
{
  "queue_id": "uuid",
  "total_reading_time_seconds": 300,
  "times_opened": 4
}
```

**PUT `/api/v1/reading/queue/{queue_id}/status`**

Updates queue item status.

**Request:**

```json
{
  "status": "completed"
}
```

**Response:**

```json
{
  "queue_id": "uuid",
  "status": "completed",
  "completed_at": "2025-12-24T10:35:00Z"
}
```

**POST `/api/v1/reading/queue/batch-dismiss`**

Bulk dismiss multiple queue items.

**Request:**

```json
{
  "queue_ids": ["uuid1", "uuid2", "uuid3"]
}
```

**Response:**

```json
{
  "dismissed_count": 3,
  "remaining_unread_count": 4
}
```

[Source: architecture/database-schema.md#reading_queue]

### Database Schema Updates

**CRITICAL:** This story requires a database migration before implementation.

The `reading_queue` table needs two additional columns:

```sql
-- Existing columns (already in schema):
times_opened INTEGER NOT NULL DEFAULT 0,
total_reading_time_seconds INTEGER NOT NULL DEFAULT 0,
completed_at TIMESTAMP,

-- NEW columns (must be added via migration):
first_opened_at TIMESTAMP,      -- Set on first view of queue item
dismissed_at TIMESTAMP          -- Set when user dismisses item
```

```tsx
export const Toast: React.FC<ToastProps> = ({
  message,
  variant,
  duration = 3000,
  onClose,
}) => {
  useEffect(() => {
    const timer = setTimeout(onClose, duration);
    return () => clearTimeout(timer);
  }, [duration, onClose]);

  const variantStyles = {
    success: "bg-green-500",
    error: "bg-red-500",
    info: "bg-blue-500",
  };

  return (
    <div
      role="status"
      aria-live="polite"
      className={`fixed bottom-4 right-4 px-4 py-3 rounded-lg text-white shadow-lg
                  ${variantStyles[variant]} animate-slide-up`}
    >
      {message}
    </div>
  );
};
```

### Time Tracking Implementation

**useReadingTimeTracker Hook:**

```typescript
export function useReadingTimeTracker(queueId: string) {
  const startTimeRef = useRef<number>(0);
  const accumulatedTimeRef = useRef<number>(0);
  const isVisibleRef = useRef<boolean>(true);

  useEffect(() => {
    startTimeRef.current = performance.now();

    // Handle visibility changes (tab switch)
    const handleVisibilityChange = () => {
      if (document.visibilityState === "hidden") {
        // Tab hidden - pause and accumulate
        accumulatedTimeRef.current += performance.now() - startTimeRef.current;
        isVisibleRef.current = false;
      } else {
        // Tab visible - resume
        startTimeRef.current = performance.now();
        isVisibleRef.current = true;
      }
    };

    // Handle page unload
    const handleUnload = () => {
      const timeSpent = calculateTimeSpent();
      if (timeSpent >= 3) {
        // Minimum 3 seconds
        // Use sendBeacon for reliable delivery
        navigator.sendBeacon(
          `/api/v1/reading/queue/${queueId}/engagement`,
          JSON.stringify({ time_spent_seconds: Math.min(timeSpent, 1800) }) // Cap at 30 min
        );
      }
    };

    document.addEventListener("visibilitychange", handleVisibilityChange);
    window.addEventListener("beforeunload", handleUnload);

    return () => {
      document.removeEventListener("visibilitychange", handleVisibilityChange);
      window.removeEventListener("beforeunload", handleUnload);
      // Send engagement on unmount (navigation)
      handleUnload();
    };
  }, [queueId]);

  const calculateTimeSpent = () => {
    const currentSession = isVisibleRef.current
      ? performance.now() - startTimeRef.current
      : 0;
    return Math.floor((accumulatedTimeRef.current + currentSession) / 1000);
  };

  return { calculateTimeSpent };
}
```

**Edge Cases Handled:**

- Tab switch: Pauses timer when hidden, resumes when visible
- Maximum cap: 30 minutes per session to prevent stale tab inflation
- Minimum threshold: 3 seconds to filter accidental opens
- Page close: Uses `sendBeacon` for reliable delivery even on page close
