# Story 3.8.1: Collapsible Results Layout - Brownfield Enhancement

## Status

**Ready for Done**

---

## Story

**As a** user viewing my diagnostic results,
**I want** the "Start Learning" CTA visible without scrolling,
**so that** I can immediately take action while optionally reviewing detailed breakdowns.

---

## Story Context

**Existing System Integration:**

- Integrates with: `DiagnosticResultsPage.tsx` and its child components from Story 3.8
- Technology: React, TypeScript, Tailwind CSS, clsx
- Pattern: New reusable `CollapsibleSection` component (no existing accordion pattern in codebase)
- Touch points: `ResultsHeroSection`, `KnowledgeAreaBreakdown`, `GapHighlights`, `UncertaintyCallout`, `RecommendationsSection`

**Problem Statement:**

Currently, the "Start Learning" CTA is positioned below the detailed diagnostic score dashboard, requiring users to scroll to see it. This reduces the visibility of the primary call-to-action and may decrease conversion to the adaptive quiz flow.

**Proposed Solution:**

Combine two UX improvements:
1. **Reorder sections**: Move the CTA directly after the score summary (hero section)
2. **Collapsible details**: Make detailed breakdowns collapsed by default with expand/collapse functionality

---

## Acceptance Criteria

1. **Reordered Layout**: The page sections appear in this order:
   - Hero section (score summary) - always visible
   - Recommendations section with CTAs - always visible, no scrolling required
   - Detailed breakdowns (collapsed by default)
   - Feedback survey

2. **Collapsible Sections**: The following sections are collapsible:
   - Knowledge Area Breakdown
   - Gap Highlights
   - Uncertainty Callout

3. **Expand/Collapse Controls**:
   - Clear "View Detailed Breakdown" button/link with chevron icon
   - Chevron rotates to indicate expanded/collapsed state
   - Smooth expand/collapse animation (respects `prefers-reduced-motion`)

4. **Default State**:
   - Detailed sections are collapsed by default
   - User can expand all sections with a single click or individual sections

5. **Persistence**: Expanded/collapsed state does not need to persist across page reloads (session-only)

6. **Accessibility**:
   - Collapsible sections use proper ARIA attributes (`aria-expanded`, `aria-controls`)
   - Keyboard accessible (Enter/Space to toggle)
   - Focus management on expand/collapse
   - Screen reader announces state changes

7. **Mobile Responsive**: Layout works correctly on mobile devices

### Animation Pattern

```tsx
// Tailwind animation for collapse
<div
  className={clsx(
    'overflow-hidden transition-all duration-300 motion-reduce:transition-none',
    isExpanded ? 'max-h-[2000px] opacity-100' : 'max-h-0 opacity-0'
  )}
>
  {children}
</div>
```

### ARIA Pattern

```tsx
<button
  id="details-toggle"
  aria-expanded={isExpanded}
  aria-controls="details-section"
  onClick={() => setIsExpanded(!isExpanded)}
>
  {isExpanded ? 'Hide Details' : 'View Detailed Breakdown'}
  <svg
    className={clsx('w-5 h-5 transition-transform', isExpanded && 'rotate-180')}
    fill="none"
    viewBox="0 0 24 24"
    stroke="currentColor"
  >
    <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M19 9l-7 7-7-7" />
  </svg>
</button>
<div id="details-section" role="region" aria-labelledby="details-toggle">
  {/* collapsed content */}
</div>
```
