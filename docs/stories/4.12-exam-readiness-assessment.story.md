# Story 4.12: Exam Readiness Assessment & Coverage Gates

## Status

**Deferred** (Sprint 10+ - Core user loop prioritized)

---

## Story

**As a** user preparing for certification,
**I want** to see a clear exam readiness assessment based on my coverage and confidence levels,
**so that** I know when I'm adequately prepared and can focus on specific weak areas.

---

## Acceptance Criteria

1. Readiness score calculated using weighted formula: (coverage × 0.4) + (confidence × 0.3) + (ka_balance × 0.3)
2. Four readiness status levels: NOT_READY (<60%), ALMOST_READY (60-79%), READY (80-89%), WELL_PREPARED (>=90%)
3. KA balance score penalizes variance between knowledge areas (1.0 - max_ka_coverage - min_ka_coverage)
4. Blocking issues identified when any KA falls below minimum threshold (60%)
5. Configurable thresholds per course (CBAP default, CFA override)
6. GET `/api/v1/readiness` returns full ReadinessAssessment schema
7. Actionable recommendations generated prioritizing: KA below threshold > low coverage > low confidence > high gaps
8. Exam date warning when exam < 7 days away and readiness < 60%
9. Performance: Readiness calculation completes in <150ms
10. Uses cached coverage data from Story 4.5 (5-minute TTL)

### Technical Constraints

**Readiness Score Formula:**
```python
readiness_score = (coverage_score * 0.4) + (confidence_score * 0.3) + (ka_balance_score * 0.3)
```

**Status Thresholds:**
| Status | Score Range |
|--------|-------------|
| NOT_READY | < 0.60 |
| ALMOST_READY | 0.60 - 0.79 |
| READY | 0.80 - 0.89 |
| WELL_PREPARED | >= 0.90 |

**KA Balance Calculation:**
```python
ka_coverages = [ka.mastered / ka.total for ka in coverage.by_knowledge_area]
ka_variance = max(ka_coverages) - min(ka_coverages)
ka_balance_score = max(0, 1.0 - ka_variance)
```

**Configurable Thresholds (default):**
```python
READINESS_CONFIG = {
    'exam_ready_coverage_threshold': 0.80,
    'exam_ready_confidence_threshold': 0.70,
    'ka_minimum_coverage_threshold': 0.60,
    'ka_imbalance_variance_threshold': 0.20,
}
```
