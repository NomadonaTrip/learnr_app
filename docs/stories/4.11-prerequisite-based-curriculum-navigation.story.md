# Story 4.11: Prerequisite-Based Curriculum Navigation

## Status

**Done**

---

## Story

**As a** user progressing through the curriculum,
**I want** the system to enforce prerequisite mastery before testing advanced concepts,
**so that** I build knowledge systematically and don't face questions I'm unprepared for.

---

## Acceptance Criteria

1. System checks prerequisite mastery before selecting questions about advanced concepts
2. "Mastery gate" requires P(mastery) > 0.7 with confidence > 0.6 for all direct prerequisites
3. Questions about locked concepts are deprioritized (soft enforcement) or excluded (hard enforcement)
4. User can see which concepts are "locked" vs "unlocked" based on prerequisite chain
5. When hovering over locked concept, user sees list of unmastered prerequisites
6. System identifies "closest to unlock" concepts (fewest remaining prerequisites)
7. Notification appears when new concepts become unlocked
8. Advanced users can override gates and attempt locked concepts (tracked for analysis)
9. Performance: Gate check < 20ms per concept, batch check < 200ms
10. Dashboard shows locked/unlocked concept counts per knowledge area

### Algorithm: Check Prerequisites Mastered

```python
async def check_prerequisites_mastered(user_id: UUID, concept_id: UUID) -> GateCheckResult:
    # 1. Get prerequisites from graph cache (O(1))
    prerequisites = self.graph_service.get_prerequisites(concept_id)

    if not prerequisites:
        return GateCheckResult(is_unlocked=True, blocking=[], closest=None, progress=1.0)

    # 2. Only check 'required' prerequisites for gate
    required_prereqs = [p for p in prerequisites if p.relationship_type == 'required']

    if not required_prereqs:
        return GateCheckResult(is_unlocked=True, blocking=[], closest=None, progress=1.0)

    # 3. Batch fetch belief states for all prerequisites
    prereq_ids = [p.prerequisite_id for p in required_prereqs]
    belief_states = await self.belief_repo.get_beliefs_by_concept_ids(user_id, prereq_ids)

    # 4. Check each prerequisite against thresholds
    blocking = []
    highest_mastery = None
    highest_mastery_value = -1

    for prereq in required_prereqs:
        belief = belief_states.get(prereq.prerequisite_id)
        if belief is None:
            # No belief state = not mastered
            blocking.append(prereq)
            continue

        mastery = belief.mastery_probability
        confidence = belief.confidence

        if mastery < MASTERY_THRESHOLD or confidence < CONFIDENCE_THRESHOLD:
            blocking.append(ConceptSummary(
                id=prereq.prerequisite_id,
                name=self.graph_service.get_concept(prereq.prerequisite_id).name,
                mastery_probability=mastery,
                confidence=confidence
            ))
            # Track closest to unlock
            if mastery > highest_mastery_value:
                highest_mastery_value = mastery
                highest_mastery = blocking[-1]

    # 5. Calculate progress
    mastered_count = len(required_prereqs) - len(blocking)
    progress = mastered_count / len(required_prereqs)

    return GateCheckResult(
        is_unlocked=(len(blocking) == 0),
        blocking_prerequisites=blocking,
        closest_to_unlock=highest_mastery,
        mastery_progress=progress
    )
```
