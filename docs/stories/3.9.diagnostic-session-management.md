# Story 3.9: Diagnostic Session Management

## Status

**Ready for Done**

---

## Story

**As a** system,
**I want** to manage diagnostic session state,
**so that** users can resume interrupted diagnostics.

---

## Acceptance Criteria

1. `diagnostic_sessions` table with schema:
   - id (UUID, PK)
   - user_id (FK)
   - question_ids (JSONB array) - selected questions for this diagnostic
   - current_index (INT) - progress through questions
   - status (ENUM: 'in_progress', 'completed', 'expired', 'reset')
   - started_at (TIMESTAMP)
   - completed_at (TIMESTAMP, nullable)
   - created_at
2. Session created when diagnostic questions fetched
3. Session updated after each answer (current_index++)
4. Session marked complete after last answer
5. Expired sessions (>30 min) marked as 'expired'
6. Only one active session per user per enrollment (enhancement from epic's "per user" to support multi-course architecture)
7. Resume support: If active session exists, return remaining questions
8. Reset endpoint: POST `/api/v1/diagnostic/reset` clears session and resets beliefs
9. Logging: Session state changes tracked
10. API returns session status for UI state management

## Dev Notes

### Architecture Context

This story implements **Diagnostic Session Management** - the state tracking layer that enables users to resume interrupted diagnostic assessments. It sits between the diagnostic UI (Story 3.6) and the belief update system (Story 3.7), providing session persistence and state management.

> **DEPENDENCY: Story 3.5 (Optimal Diagnostic Question Selection)**
> This story calls the question selection service from 3.5 when starting a new diagnostic session.

> **DEPENDENCY: Story 3.6 (Diagnostic Assessment UI)**
> The frontend uses session status returned by these endpoints to manage UI state.

> **DEPENDENCY: Story 3.7 (Diagnostic Belief State Updates)**
> Belief updates happen per-answer, but session management coordinates the flow.

> **DEPENDENCY: Story 3.4 (Belief State Initialization)**
> The reset endpoint calls belief initialization to restore Beta(1,1) priors.

**Key Design Decisions:**

> **Enhancement from Epic:** Added `enrollment_id` to support multi-course architecture per `docs/architecture/database-schema.md`. The epic schema only specified `user_id`, but multi-course support requires scoping sessions to enrollments.

- **One active session per enrollment**: Prevents confusion from multiple concurrent diagnostics
- **30-minute timeout**: Balances resume convenience with fresh assessment value
- **Explicit reset**: Requires confirmation to prevent accidental data loss
- **Session-based question ordering**: Questions cached in session, not reselected on resume
- **Status-based access control**: Results only available for 'completed' sessions

### Database Schema

> **Relationship to quiz_sessions:** The architecture has two session tables:
> - `quiz_sessions` (existing) - Tracks adaptive quiz sessions with flexible question selection
> - `diagnostic_sessions` (this story) - Tracks diagnostic assessments with fixed question sets
>
> Key differences:
> | Aspect | quiz_sessions | diagnostic_sessions |
> |--------|---------------|---------------------|
> | Question order | Dynamic (selected per-question) | Fixed (cached at start) |
> | Resume behavior | Continue with new questions | Resume exact question set |
> | Purpose | Ongoing learning | Initial assessment |
> | Session types | adaptive, focused, review | diagnostic only |

#### diagnostic_sessions Table

```sql
CREATE TABLE diagnostic_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    enrollment_id UUID NOT NULL REFERENCES enrollments(id) ON DELETE CASCADE,
    question_ids JSONB NOT NULL,           -- Array of question UUIDs in order
    current_index INTEGER NOT NULL DEFAULT 0,
    status VARCHAR(20) NOT NULL DEFAULT 'in_progress',
    started_at TIMESTAMP NOT NULL DEFAULT NOW(),
    completed_at TIMESTAMP,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),
    CHECK (status IN ('in_progress', 'completed', 'expired', 'reset')),
    CHECK (current_index >= 0)
);

-- Indexes
CREATE INDEX idx_diagnostic_sessions_user ON diagnostic_sessions(user_id);
CREATE INDEX idx_diagnostic_sessions_enrollment ON diagnostic_sessions(enrollment_id);
CREATE INDEX idx_diagnostic_sessions_user_active ON diagnostic_sessions(user_id, status)
    WHERE status = 'in_progress';
CREATE INDEX idx_diagnostic_sessions_stale ON diagnostic_sessions(started_at)
    WHERE status = 'in_progress';

-- Unique constraint: only one active session per enrollment
CREATE UNIQUE INDEX idx_diagnostic_sessions_active_enrollment
    ON diagnostic_sessions(enrollment_id)
    WHERE status = 'in_progress';
```

```python
from src.db.session import Base

class DiagnosticSession(Base):
    __tablename__ = "diagnostic_sessions"

    id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    user_id = Column(UUID(as_uuid=True), ForeignKey("users.id", ondelete="CASCADE"), nullable=False)
    enrollment_id = Column(UUID(as_uuid=True), ForeignKey("enrollments.id", ondelete="CASCADE"), nullable=False)
    question_ids = Column(JSONB, nullable=False)  # List[str] of question UUIDs
    current_index = Column(Integer, nullable=False, default=0)
    status = Column(String(20), nullable=False, default="in_progress")
    started_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    completed_at = Column(DateTime, nullable=True)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    updated_at = Column(DateTime, nullable=False, default=datetime.utcnow, onupdate=datetime.utcnow)

    # Relationships
    user = relationship("User", back_populates="diagnostic_sessions")
    enrollment = relationship("Enrollment", back_populates="diagnostic_sessions")

    __table_args__ = (
        CheckConstraint("status IN ('in_progress', 'completed', 'expired', 'reset')", name="diagnostic_session_status_check"),
        CheckConstraint("current_index >= 0", name="diagnostic_session_index_check"),
        Index("idx_diagnostic_sessions_user", "user_id"),
        Index("idx_diagnostic_sessions_enrollment", "enrollment_id"),
        Index("idx_diagnostic_sessions_user_active", "user_id", "status", postgresql_where=(status == "in_progress")),
    )

    @property
    def questions_total(self) -> int:
        return len(self.question_ids) if self.question_ids else 0

    @property
    def questions_remaining(self) -> int:
        return max(0, self.questions_total - self.current_index)

    @property
    def is_complete(self) -> bool:
        return self.status == "completed"
```

### Service Implementation

```python
# apps/api/src/services/diagnostic_session_service.py
from typing import Tuple, List, Optional
from uuid import UUID
from datetime import datetime, timedelta
import structlog

from sqlalchemy.ext.asyncio import AsyncSession

from src.models.diagnostic_session import DiagnosticSession
from src.models.question import Question
from src.repositories.diagnostic_session_repository import DiagnosticSessionRepository
from src.repositories.belief_repository import BeliefRepository
from src.repositories.question_repository import QuestionRepository
from src.services.question_selector import QuestionSelector

logger = structlog.get_logger()

class DiagnosticSessionService:
    """
    Manages diagnostic session lifecycle: creation, resumption, expiration, reset.
    """

    SESSION_TIMEOUT_MINUTES = 30

    def __init__(
        self,
        db: AsyncSession,
        session_repo: DiagnosticSessionRepository,
        belief_repo: BeliefRepository,
        question_repo: QuestionRepository,
        question_selector: QuestionSelector
    ):
        self.db = db
        self.session_repo = session_repo
        self.belief_repo = belief_repo
        self.question_repo = question_repo
        self.question_selector = question_selector

    async def start_or_resume_session(
        self,
        user_id: UUID,
        enrollment_id: UUID
    ) -> Tuple[DiagnosticSession, List[Question], bool]:
        """
        Start a new diagnostic session or resume existing one.

        Returns: (session, questions, is_resumed)
        """
        # Check for existing active session
        existing = await self.session_repo.get_active_session(user_id, enrollment_id)

        if existing:
            if self._is_session_expired(existing):
                # Expire old session, create new
                await self.session_repo.mark_expired(existing.id)
                logger.info(
                    "Expired stale diagnostic session",
                    user_id=str(user_id),
                    session_id=str(existing.id)
                )
                return await self._create_new_session(user_id, enrollment_id), False
            else:
                # Resume existing session - return remaining questions
                questions = await self._get_remaining_questions(existing)
                logger.info(
                    "Resuming diagnostic session",
                    user_id=str(user_id),
                    session_id=str(existing.id),
                    current_index=existing.current_index
                )
                return existing, questions, True

        # No active session - create new
        session, questions = await self._create_new_session(user_id, enrollment_id)
        return session, questions, False

    async def _create_new_session(
        self,
        user_id: UUID,
        enrollment_id: UUID
    ) -> Tuple[DiagnosticSession, List[Question]]:
        """
        Create new diagnostic session with selected questions.

        Returns: (session, questions) - Note: caller adds is_resumed bool
        """
        # Select optimal questions for diagnostic
        questions = await self.question_selector.select_diagnostic_questions(
            enrollment_id=enrollment_id,
            target_count=15
        )

        question_ids = [str(q.id) for q in questions]

        session = await self.session_repo.create_session(
            user_id=user_id,
            enrollment_id=enrollment_id,
            question_ids=question_ids
        )

        logger.info(
            "Created new diagnostic session",
            user_id=str(user_id),
            session_id=str(session.id),
            question_count=len(questions)
        )

        return session, questions

    async def record_answer(
        self,
        session_id: UUID,
        question_id: UUID,
        user_id: UUID
    ) -> DiagnosticSession:
        """
        Record answer submission and advance session progress.
        Belief updates handled separately by BeliefUpdater service.
        """
        session = await self.session_repo.get_session_by_id(session_id)

        if not session or session.user_id != user_id:
            raise ValueError("Session not found or unauthorized")

        if session.status != "in_progress":
            raise ValueError(f"Session is {session.status}, cannot record answer")

        # Validate question is at expected position
        expected_question_id = session.question_ids[session.current_index]
        if str(question_id) != expected_question_id:
            raise ValueError("Question does not match expected position in session")

        # Advance progress
        session = await self.session_repo.increment_progress(session_id)

        # Check if completed
        if session.current_index >= len(session.question_ids):
            session = await self.session_repo.mark_completed(session_id)
            logger.info(
                "Diagnostic session completed",
                user_id=str(user_id),
                session_id=str(session_id)
            )

        return session

    async def reset_diagnostic(
        self,
        user_id: UUID,
        enrollment_id: UUID
    ) -> dict:
        """
        Reset diagnostic: clear session and reset all belief states.
        """
        # Mark any active session as reset
        active_session = await self.session_repo.get_active_session(user_id, enrollment_id)
        if active_session:
            await self.session_repo.mark_reset(active_session.id)

        # Reset all belief states to Beta(1,1)
        beliefs_reset = await self.belief_repo.reset_beliefs_for_enrollment(
            user_id=user_id,
            enrollment_id=enrollment_id,
            alpha=1.0,
            beta=1.0
        )

        logger.info(
            "Diagnostic reset completed",
            user_id=str(user_id),
            enrollment_id=str(enrollment_id),
            beliefs_reset=beliefs_reset
        )

        return {
            "session_cleared": active_session is not None,
            "beliefs_reset_count": beliefs_reset
        }

    def _is_session_expired(self, session: DiagnosticSession) -> bool:
        """Check if session has exceeded timeout."""
        timeout = timedelta(minutes=self.SESSION_TIMEOUT_MINUTES)
        return datetime.utcnow() > session.started_at + timeout

    async def _get_remaining_questions(
        self,
        session: DiagnosticSession
    ) -> List[Question]:
        """Get questions starting from current_index."""
        remaining_ids = session.question_ids[session.current_index:]
        # Fetch questions in order
        return await self.question_repo.get_questions_by_ids(remaining_ids)
```

```python
# apps/api/src/repositories/question_repository.py (ADD)
async def get_questions_by_ids(
    self,
    question_ids: List[str],
    preserve_order: bool = True
) -> List[Question]:
    """
    Fetch questions by list of IDs, preserving order if specified.
    Used for resuming diagnostic sessions with cached question order.
    """
    query = select(Question).where(Question.id.in_([UUID(qid) for qid in question_ids]))
    result = await self.db.execute(query)
    questions = result.scalars().all()

    if preserve_order:
        # Reorder to match input order
        question_map = {str(q.id): q for q in questions}
        return [question_map[qid] for qid in question_ids if qid in question_map]

    return list(questions)
```

```python
# apps/api/src/repositories/belief_repository.py (ADD)
async def reset_beliefs_for_enrollment(
    self,
    user_id: UUID,
    enrollment_id: UUID,
    alpha: float = 1.0,
    beta: float = 1.0
) -> int:
    """
    Reset all belief states for a user's enrollment to uninformative prior.
    Returns count of beliefs reset.

    Note: Beliefs are tied to concepts, which are tied to courses via enrollment.
    """
    # Get course_id from enrollment
    enrollment = await self.db.execute(
        select(Enrollment).where(Enrollment.id == enrollment_id)
    )
    enrollment = enrollment.scalar_one()

    # Reset beliefs for all concepts in this course
    result = await self.db.execute(
        update(BeliefState)
        .where(
            and_(
                BeliefState.user_id == user_id,
                BeliefState.concept_id.in_(
                    select(Concept.id).where(Concept.course_id == enrollment.course_id)
                )
            )
        )
        .values(alpha=alpha, beta=beta, response_count=0, last_response_at=None)
    )

    await self.db.commit()
    return result.rowcount
```

### Session Timeout Logic

The 30-minute timeout provides balance between:
- **User convenience**: Can resume if interrupted by phone call, break, etc.
- **Assessment validity**: Fresh answers more valuable than stale recall

```python
SESSION_TIMEOUT_MINUTES = 30

def is_session_expired(session: DiagnosticSession) -> bool:
    """
    Session expires 30 minutes after started_at timestamp.

    Timeline:
    - 0:00 - Session created, user starts diagnostic
    - 0:25 - Warning shown in UI (from Story 3.6)
    - 0:30 - Session marked expired on next API call
    - 0:30+ - New session created automatically
    """
    expiry_time = session.started_at + timedelta(minutes=SESSION_TIMEOUT_MINUTES)
    return datetime.utcnow() > expiry_time
```

```python
# apps/api/src/tasks/diagnostic_tasks.py

from celery import shared_task
from datetime import datetime, timedelta
import structlog

from src.db.session import get_db_session
from src.repositories.diagnostic_session_repository import DiagnosticSessionRepository

logger = structlog.get_logger()

@shared_task(bind=True, max_retries=3)
def expire_stale_diagnostic_sessions(self):
    """
    Background task to mark stale diagnostic sessions as expired.
    Runs every 5 minutes via Celery Beat.
    """
    try:
        async with get_db_session() as db:
            repo = DiagnosticSessionRepository(db)
            expired_count = await repo.expire_stale_sessions(timeout_minutes=30)

            logger.info(
                "diagnostic_sessions_expiration_complete",
                expired_count=expired_count,
                task_id=self.request.id
            )

            return {"expired_count": expired_count}

    except Exception as e:
        logger.error(
            "diagnostic_sessions_expiration_failed",
            error=str(e),
            task_id=self.request.id
        )
        raise self.retry(exc=e, countdown=60)
```
