# Story 4.9: Post-Session Review Mode

## Status

**Done**

## Story

**As a** user who got questions wrong,
**I want** to immediately review my incorrect answers after a session ends,
**so that** I can reinforce correct understanding while the material is fresh.

## Acceptance Criteria

1. When session ends (manually or suggested), check for incorrect answers
2. If incorrect answers exist, offer review:
   - "You missed 5 questions. Review now for better retention?"
   - "Skip Review" / "Start Review"
3. Review mode re-presents incorrect questions
4. **Review UI:**
   - "REVIEW" badge on question
   - "Review Question 1 of 5"
   - Same 4 options, no indication of previous answer
5. On re-answer:
   - If now correct: "Great improvement!"
   - If still incorrect: Show correct answer, explanation, reading link
6. **Belief update on review:**
   - Reinforced (incorrect → correct): Stronger positive update
   - Still incorrect: Maintain or slightly decrease belief
7. Review session tracks:
   - `total_reviewed`, `reinforced_count`, `still_incorrect_count`
8. After review, show summary:
   - "Reinforced 4/5 questions!"
   - List still-incorrect concepts with study links
9. Skip tracking: If user skips review, log for analytics
10. Analytics: Review completion rate, reinforcement rate

### Belief Update on Review (AC: 6)

**Reinforcement Modifier Logic:**

```python
# In BeliefUpdater service
REINFORCEMENT_MULTIPLIER = 1.5  # Stronger positive update
STILL_INCORRECT_MULTIPLIER = 0.5  # Weaker negative update

def update_beliefs_for_review(
    self,
    user_id: UUID,
    question: Question,
    is_correct: bool,
    was_reinforced: bool,
    beliefs: Dict[UUID, BeliefState]
) -> Dict[UUID, BeliefState]:
    """
    Update beliefs with reinforcement modifier for review answers.

    Reinforcement (incorrect→correct) indicates deeper learning,
    so we apply a stronger positive update.

    Still-incorrect indicates persistent confusion, but we don't
    want to overly penalize since they're actively reviewing.
    """
    updates = {}

    for concept_id in question.concept_ids:
        belief = beliefs[concept_id]
        slip = question.slip_rate or self.default_slip
        guess = question.guess_rate or self.default_guess

        # Standard Bayesian update
        new_alpha, new_beta = self._bayesian_update(
            belief.alpha, belief.beta,
            is_correct, slip, guess
        )

        # Apply reinforcement modifier
        if was_reinforced:
            # Stronger positive update
            delta_alpha = (new_alpha - belief.alpha) * REINFORCEMENT_MULTIPLIER
            new_alpha = belief.alpha + delta_alpha
        elif not is_correct:
            # Weaker negative update (still reviewing = effort)
            delta_beta = (new_beta - belief.beta) * STILL_INCORRECT_MULTIPLIER
            new_beta = belief.beta + delta_beta

        updates[concept_id] = BeliefState(
            user_id=user_id,
            concept_id=concept_id,
            alpha=new_alpha,
            beta=new_beta,
            response_count=belief.response_count + 1
        )

    return updates
```

**State Details:**
- `SHOWING_QUESTION`: Display question with REVIEW badge, submit button disabled
- `ANSWER_SELECTED`: User selected an option, submit button enabled
- `SUBMITTING`: API call in progress, show loading spinner on submit button
- `SHOWING_FEEDBACK`: Display result (reinforced/still-incorrect), show explanation if incorrect, Next button visible
- `COMPLETE`: All review questions answered, trigger navigation to summary
